Desktop preview. Open this page in Quest Browser and enter VR.

Near: pinch an object to grab it. Far: point your index finger at an object and pinch to pull it to your hand. Two hands: pinch the same object to scale and rotate it. Release: leave it floating. Reset: return everything home.

Includes floating panels and objects. Experimental hand tracking; Quest 3 verification required.
